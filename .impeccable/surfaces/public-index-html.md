Scope: public/index.html, the single working screen. Mode: Operate.
Audience/job: the developer, page open beside the editor while a sender posts webhooks; copy the URL, flip the simulated response, inspect what arrived.

## Direction contract

THESIS: Deliveries are mail on a sorting table; each one is cancelled with a postmark that states when it arrived and what we answered. Refuses the grey dashboard of identical JSON cards.
OWN-WORLD: Air-mail palette: navy shell band edged with a red/white/blue chevron stripe, cool paper ground (light) or night navy (dark), white/raised sheets. Ink colors carry state only: green ink = 2xx, red ink = 4xx/invalid. System sans for UI, monospace only for payloads, headers and URLs.
STORY: The visitor sees the delivery address, copies it, sees which response is armed, then watches deliveries land and opens one to read payload, headers and the answer.
FIRST VIEWPORT: Navy header with name + live count. Below, one row: delivery address field with Copiar (left, wide) and the armed-response radio group (right). Then the delivery list fills the rest; empty state shows a ready curl command.
FORM: pick card "Matasellos" (my #1 of 7; assigned was #6 Telegrama). seed:b99b1387b4f39a24. Signature move: circular SVG postmark per delivery (time on the ring, status code in the center, wavy cancellation lines), new arrivals stamp in once (scale+opacity, 220ms, none under reduced motion).
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
